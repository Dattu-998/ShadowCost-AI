# Demo video script (about 3 minutes)

Record the deployed site at 1280×720. Wake the API first (open `/app` once and wait), and
approve nothing beforehand, so the approval happens on camera.

| Time | Screen | Say |
|---|---|---|
| 0:00 | Landing page, first screen | "Small companies run on spreadsheets and email. ShadowCost finds the repetitive parts and hands them to agents, but only after each agent proves itself against what the person actually did." |
| 0:15 | Scroll to "Bank line in, invoice out"; click the three example lines, then type a messy one | "This is the linker, the same logic the backend uses. A payment with a clean reference, a mangled one, none at all: it finds the invoice, or says why it won't guess." |
| 0:40 | Scroll through "Trust, earned in four steps" | "Every agent climbs four stages: it watches, it drafts, it asks, it acts. This is the invoice agent's real path through a simulated year." |
| 0:55 | "The files you already have", then "47.7 h" | "It reads ordinary files, no event logs. And the savings are measured against the minutes the person really spent: 47.7 hours, above the 40.9 estimated." |
| 1:10 | "Open the demo": type your name, choose "A full year", open | "The demo opens with my name as the approver." |
| 1:20 | **Discover**: click the chasing workflow | "Three workflows found. For chasing it recovered the rule itself: Mondays and Thursdays, at least 7 days past due, unpaid." |
| 1:40 | **Agents**: show W1's rules and email, then **Approve**; same for W2 | "An LLM drafted each agent as data, not code. On days it never saw, the invoice agent matched the person 100% of the time. Nothing runs until I approve it." |
| 2:05 | **Shadow mode**: W1, then W2, then W3 | "Over the year the invoice agent earns autonomy by July. The payment agent needs longer in shadow, then gets there. The chasing agent isn't even approved, and wouldn't climb: chasing needs judgment." |
| 2:30 | **Execute**: W2, a day in May, stage Approval, run; approve one action in the queue | "At the approval stage each action waits for a click. Nothing is ever sent or overwritten." |
| 2:45 | **Report**: build it, scroll to Savings | "And the report shows what it saved, with every assumption written down. Code, tests and the write-ups are on GitHub." |

Upload the video (YouTube unlisted or Loom) and link it at the top of the README.
