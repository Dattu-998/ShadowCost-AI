# ShadowCost web

The landing page and the product app, in Next.js 16. The app talks to the ShadowCost API
(FastAPI, `src/shadowcost/api.py`), which runs on Render; this folder deploys to Vercel.

```bash
cp .env.example .env.local   # NEXT_PUBLIC_API_URL points at the API
npm install
npm run dev                  # http://localhost:3000, with the API on :8000
```

Run the API alongside it from the repository root:

```bash
uvicorn shadowcost.api:app --reload
```

## Design

Both surfaces were art-directed with the taste skill and pass its browser inspector with no
failures on the production build.

- **Landing page:** the "Colour chapters" direction. The four stages an agent climbs are four
  colour chapters (slate, blush, sage, olive), and olive, the colour of acting alone, is the
  only colour that acts. Its one live thing is the bank-line linker: a browser port of the
  backend's linking logic, run on the sample's real invoices.
- **App:** the "Framed sheet" style. A slate-tinted frame, the work on a white sheet, colour
  only on data, and each agent's ladder as the signature element.

`src/data/landing.json` is generated by `scripts/export_landing_data.py`, so every number on
the landing page comes from the real pipeline. The two archival pictures are credited in the
footer and listed in `src/data/credits.json`.
